Light curve photometry,
on your desktop

Starflux is a native desktop app for differential aperture photometry on FITS image series — exoplanet transits, variable stars, asteroid occultations, and other light-curve science. Spiritual successor to FotoDif.

Download Starflux View source

Built for the observing session

A complete workflow from raw FITS frames to a publishable light curve.

FITS image series

Load a single file, multiple files, or an entire folder of an observing run.

Aperture photometry

Sub-pixel centroiding, aperture sum, and sigma-clipped sky annulus background subtraction.

Differential light curves

Target, comparison, and check stars — named and unlimited, not fixed to three.

Resumable sessions

Save and restore star positions and processed results — pick up an interrupted run exactly where it left off.

Observer mode

A red-light theme that preserves night vision at the telescope, toggled live with no restart.

AAVSO export

Export results in the AAVSO Extended File Format, ready to submit.

Grab the latest release once the alpha ships. Binaries are not code-signed yet: macOS Gatekeeper and Windows SmartScreen will warn on first launch.

macOS
starflux-darwin-arm64.dmg Apple Silicon starflux-darwin-amd64.dmg Intel
Windows
starflux-windows-amd64-setup.exe x86_64
Linux
starflux-linux-amd64.tar.gz x86_64 starflux-linux-arm64.tar.gz ARM64

macOS: right-click the app inside the mounted .dmg and choose "Open" instead of double-clicking (or run xattr -cr Starflux.app from Terminal). Windows: click "More info" → "Run anyway" on the SmartScreen prompt.
